# Покрокова система вивчення лексики — лендінг

Пересобраний лендінг вебінару Олександри Гречич. Замінює версію з конструктора
SendPulse: той самий зміст і та сама палітра, але власна верстка й анімації.

**Стек:** Astro 7 (статична генерація) · Tailwind 4 · GSAP + ScrollTrigger · Lenis

## Команди

| Команда           | Що робить                              |
| :---------------- | :------------------------------------- |
| `npm install`     | Встановити залежності                  |
| `npm run dev`     | Дев-сервер на `localhost:4321`         |
| `npm run build`   | Зібрати продакшн у `./dist/`           |
| `npm run preview` | Переглянути зібране локально           |

## Де правити тексти

**Уся копія лежить в одному файлі — [`src/data/content.ts`](src/data/content.ts).**
Щоб змінити заголовок, ціну, питання FAQ чи посилання на оплату, редагуйте його,
а не компоненти. У коді немає жодного захардкоженого рядка тексту.

Ключові значення там:

- `payUrl` — посилання WayForPay для всіх кнопок оплати одразу
- `socials` — Instagram, YouTube, email

### Блоки, позначені `DRAFT`

Цих секцій не було на оригінальному лендінгу, я склав їх чернетками — перечитайте
й перепишіть під себе:

- `programSection` — «5 кроків від хаосу до системи». Питання взяті зі слайдів
  самого вебінару, але формулювання описів мої.
- `faqSection` — шість питань-відповідей.

Решта текстів перенесена з поточного сайту дослівно.

## Палітра

Збережена з оригіналу: кремовий `#FEF9EE`, лісовий зелений `#486A5A`, темний
`#141E19`, пісочний `#E5E4C8`, золотий `#E3CF82`, кораловий `#FF6464`.
Токени — у `@theme` в [`src/styles/global.css`](src/styles/global.css).

Шрифти: **Unbounded** (заголовки) + **Onest** (текст), обидва з кирилицею.

## Анімації

Логіка в [`src/scripts/animations.ts`](src/scripts/animations.ts): плавний скрол
Lenis, reveal секцій, паралакс фото, магнітні кнопки, акордеон FAQ і «поле слів»
у героєві — картки німецької лексики складаються з хаосу в систему під час скролу.

Усе вимикається при `prefers-reduced-motion: reduce`. Відео YouTube вантажиться
лише після кліку на обкладинку.

## Деплой

Статика, тож підходить будь-який хостинг.

- **Netlify** — конфіг уже є (`netlify.toml`), нічого налаштовувати не треба.
- **Vercel** — визначає Astro автоматично; команда `npm run build`, тека `dist`.
- **Свій хостинг** — `npm run build` і залийте вміст `dist/`.
